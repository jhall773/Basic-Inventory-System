# Basic-Inventory-System
Uses an SQLite database file with a key constraint of unique item names only to match with Python's dictionary data structures and store user-entered items and quantities.

## Note: 
- Please run the system either by running the Python file **"Inventory_System.py"** with the **"Database_setUp.py"** file and the **"inventory.db"** database file in the same folder or directory or run the **"Inventory_System.exe"** and the **"inventory.db"** database file in the same folder or directory.

- Also, please be sure to only enter in an integer 1-4 when being prompted to choose an action to do in the system (not including spaces or dots like "4."). 

- To see an example of how to use the system when running the program, please see the **Example_of_Running_the_System.png** image.
