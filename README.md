# Basic-Inventory-System
Uses an SQLite database file with a key constraint of unique item names only to match with Python's dictionary data structures and store user-entered items and quantities.

## Note: Please run the system either by running the Python file "Inventory_System.py" with the "Database_setUp.py" file and the "inventory.db" database file in the same folder or directory or run the "Inventory_System.exe" with the "Database_setUp.exe" file and the "inventory.db" database file in the same folder or directory.
